WHAT YOU GET

  • █▄ THREE WAYS IN

    Telnet, SSH and both secure and non-secure WebSocket access built in, with unlimited nodes. Additional servers are easy to implement.

  • █▄ FIDONET, NATIVELY

    A native BinkP/1.1 mailer — inbound listener and outbound caller, no external binkd. Crashmail ships on export; a pull cycle keeps echo mail coming from quiet hubs.

  • █▄ DOS DOORS THAT RUN

    Native x86 emulation via v86 — LORD, PimpWars, TradeWars — with zero external dependencies. No QEMU, DOSBox or DOSEMU. Plus BBSLink, DoorParty and Exodus.

  • █▄ INTERACTIVE FICTION

    Z-Machine support runs Infocom classics natively in Node.js. Zork, Colossal Cave and hundreds more from the IF Archive. Versions 3, 4, 5 and 8.

  • █▄ INDEXED FILE BASES

    Gazelle-inspired file bases with fully indexed full-text search and #tags. FILE_ID.DIZ and NFO extraction on upload. Legacy X/Y/Z modem still works.

  • █▄ ART AS IT WAS DRAWN

    CP437 and UTF-8 with wide-character support, full SAUCE, SyncTERM-style fonts and baud emulation. View ANSI like the block gods intended.

  • █▄ MAIL BEYOND FTN

    Internet mail over IMAP/SMTP straight from the private message base, MRC relay chat, and experimental ActivityPub federation with WebFinger and NodeInfo2.

  • █▄ READ IT ANYWHERE

    Message bases exposed over Gopher and NNTP, plus a built-in web server with HTTP(S) for temporary download URLs and file browsing.

  • █▄ YOURS TO SHAPE

    HJSON configuration, menus and themes, Renegade-style pipe codes, MCI codes for lightbars and input areas, and JavaScript mods when config runs out.

  • █▄ MODERN UNDERNEATH

    PBKDF2-backed passwords, two-factor auth with one-time passwords, SQLite storage and structured Bunyan logging. Runs anywhere modern Node.js does.

  • █▄ A FULL SCREEN EDITOR

    ANSI art support, live cursor and mode indicators, inline find with Ctrl-F, and file upload straight into a message body.

  • █▄ GAMIFIED

    An expandable achievement system, and a remote-accessible Waiting For Caller dashboard for the sysop.

▀▀ WHERE THIS CAME FROM

ENiGMA½ was started in October 2015, out of a lack of diversity in the BBS scene and no modern open source option to reach for. You can still read the original announcement. It has been developed in the open ever since, led by NuSkooler with contributions from many others.
